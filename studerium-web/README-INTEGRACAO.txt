# Studerium — versão integrada

Esta versão junta o siteTCC com as funcionalidades do SitePI.

- O CSS original do siteTCC foi mantido.
- As funcionalidades de alunos, faltas, notas, trabalhos, relatórios e estratégias adaptadas foram integradas.
- Os dados são salvos no localStorage do navegador.
- `app.js` contém a camada de dados compartilhada.
- `integracao.css` é apenas um complemento para os novos componentes; os arquivos CSS originais do siteTCC não foram substituídos.
- A página `turma-selecionada.html` agora usa os dados e links funcionais do SitePI.
